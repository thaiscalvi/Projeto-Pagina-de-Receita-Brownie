# Projeto: Página de Receita - Brownie 🍫

Este projeto é uma adaptação da página de receita de cupcake de café com chantilly, agora trazendo a receita de um delicioso brownie!  
O objetivo foi **praticar a estruturação HTML**, a **estilização CSS** e **treinar ajustes no layout e no rodapé**.

---

### 🔗 Acesse o projeto publicado:
👉 [Clique aqui para abrir a página de receita de Brownie](https://thaiscalvi.github.io/Projeto-Pagina-de-Receita-Brownie/)

---

### 📚 Sobre o projeto:

- Página estruturada com **HTML semântico**;
- Estilizada com **CSS3**;
- Layout **responsivo** e **organizado**;
- Conteúdo objetivo e visualmente agradável;
- Exercício de adaptação de layout baseado em um projeto anterior (cupcake).

---

### 🚀 Melhorias aplicadas:

- Redução e centralização da imagem do topo;
- Ajuste de altura e posição do ícone do rodapé;
- Separação clara entre conteúdo principal e rodapé;
- Estilização para melhor fluidez e visualização da página.
